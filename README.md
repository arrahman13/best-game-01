TIDEWALL — a round-based 5v5 tactical FPS in the browser, set on a container harbour at dusk. The Breakers plant a breach charge at site A (Fuel Farm) or B (Crane Pad) and hold it for 35 seconds; the Wardens defend and defuse. Full match loop: 12-second buy phases, five weapons, three grenades, bot teams on both sides, and a charge-hunt that punishes a passive carrier. First team to 7 rounds wins.

## Run it

```sh
node serve.ts        # then open http://localhost:8080 to play
node main.ts         # builds the make.fun dossier into /output
```
